# АСОШ Таймер — сайт

Сайт-визитка приложения «АСОШ Таймер» (умный дневник АСОШ №2): описание возможностей и инструкции по установке на Android, iPhone и компьютер.

Обычный статический сайт без сборки: `index.html`, `style.css`, `main.js`. Публикуется на Vercel автоматически при каждом коммите в `main`.

## Ссылки на скачивание

Ссылки задаются в конце `index.html`:

```js
window.LINKS = {
  app: '',   // адрес веб-версии приложения
  apk: '',   // прямая ссылка на .apk файл
};
```

Пока ссылка пустая, кнопка показывает «скоро».

## Локальный просмотр

```bash
python3 -m http.server 4173
```

Затем откройте http://localhost:4173
